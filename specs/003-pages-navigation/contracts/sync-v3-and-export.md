# Contract: синхронизация v3 и выгрузка

Основа — `../002-rich-blocks-text/contracts/sync-and-files-api.md` (формат пачки v2). Сервер не меняется: он хранит зашифрованные пачки и файлы.

## Пачка

- `formatVersion`: 3. Mac с `currentFormatVersion` 2 пачку v3 не применяет, ждёт и показывает «Обновите MyNotion на этом Mac» (как 1 → 2).
- Пачки v2 читаются как раньше; новых полей в них нет.

## Новые значения изменения страницы (`entity: page`)

| field | value | Пример |
|-------|-------|--------|
| `cover` | `null` или `{"source": {"gallery": "gradients_3"}, "offset": 0.5}` или `{"source": {"file": AttachmentRef}, "offset": 0.42}` | |
| `isFullWidth` | bool | `true` |
| `isSmallText` | bool | `false` |
| `favorite` | `null` или ключ порядка (строка дробного ключа 001) | `"a0V"` |
| `visitedAt` | `null` или дата ISO 8601 с миллисекундами | `"2026-10-20T09:15:03.120Z"` |
| `isTemplate` | bool | `true` |

- У каждого поля своя метка `hlc`; применяется, если она позже метки поля у страницы.
- `cover.offset` урезается к 0…1; неизвестный id галереи хранится как есть.
- Файл обложки — `AttachmentRef` 002: Mac, получивший обложку-файл без самого файла, ставит его в очередь докачки 002 и до того показывает заглушку.

## Дата в строке

У стиля `date` необязательный ключ `templateRelative`: `"today"` | `"now"`. Старые версии его не знают и сохраняют при записи (неизвестные ключи даты переносятся).

## Блок

`props.movedFrom` — обычный ключ `props` 002; синхронизируется как `props`.

## Не передаётся

Вкладки, история «назад/вперёд», свёрнутость разделов панели (`window_state`), версии (`page_version`, `page_version_due`), обратные ссылки (`page_link`).

## Снимок для нового Mac

Снимок v3 (002, «снимок со всеми потоками») содержит новые поля страниц. Mac, подключённый заново, получает избранное, недавние, обложки, вид и шаблоны; версии на нём начинаются заново.

## Выгрузка в Markdown

Сразу под строкой `# Название`:

```markdown
<!-- mynotion:cover gallery=gradients_3 offset=0.5 -->
<!-- mynotion:cover file="Обложка.jpg" offset=0.42 -->
```

- Своя картинка — копия файла в папке страницы под именем `Обложка.<расширение>` (при занятом — `Обложка 2.…`).
- Обратный импорт своей выгрузки ставит обложку из комментария; файл копируется в хранилище 002.
- Импорт выгрузки Notion обложек не получает (их нет в «Markdown & CSV»); отчёт импорта: «Обложки страниц Notion в выгрузку не попадают».
- Вид страницы, избранное, недавние, шаблоны, версии — не выгружаются.
