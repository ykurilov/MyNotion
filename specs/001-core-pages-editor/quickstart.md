# Quickstart: проверка ядра MyNotion

Как убедиться, что первая версия работает. Детали — в [contracts/](contracts/) и [data-model.md](data-model.md).

## Подготовка

- Mac на macOS 26, Xcode 26, XcodeGen; для сервера — Node.js 22 и pnpm.
- `xcodegen generate` в корне → `MyNotion.xcodeproj`.
- Сервер локально: `cd server && pnpm install && pnpm dev` → `http://localhost:8787/health` отвечает `ok`.

## Проверки по историям

| История | Команда | Ожидание |
|---------|---------|----------|
| Все модули | `xcodebuild test -scheme MyNotion` | все тесты зелёные |
| US1 сохранение | XCUITest `NoteSurvivesRelaunchTests` | текст совпадает после перезапуска и после принудительного завершения (потеря ≤ 1 с) |
| US2 дерево | XCUITest `PageTreeTests` | дерево из 3 уровней, перенос ветки, корзина и возврат переживают перезапуск |
| US3 блоки | XCUITest `BlockEditingTests` | все быстрые символы, меню «/», чекбокс, перестановка, ⌘Z/⇧⌘Z |
| US4 поиск | XCUITest `PageSearchTests` | на 1 000 страниц слово находит нужную, Enter открывает |
| US5 синхронизация | `pnpm test` в `server/` + `SyncConvergenceTests` | два клиента с локальным сервером: правка доходит, правки без связи сливаются, конфликт текста создаёт выбор, 0 потерь |
| US6 импорт | `NotionImportTests` на образце выгрузки в `Tests/Fixtures/notion-export/` | дерево и текст совпадают, отчёт перечисляет упрощённое |

## Замеры бюджета (принцип II, условия — research.md R13)

`xcodebuild test -scheme MyNotionPerformance -configuration Release` на эталонной базе (1 000 страниц, 100 000 блоков):

| Показатель | Предел |
|------------|--------|
| Запуск до готовности к вводу | ≤ 1 с |
| Память в покое | ≤ 200 МБ |
| Отклик набора и перехода, p95 | ≤ 50 мс |
| Поиск, на символ | ≤ 100 мс |
| Импорт 1 000 страниц | ≤ 60 с |

## Живая проверка на двух Mac

1. Сервер развёрнут на `mynotion.kurilov.cloud` (скилл server-deploy), `/health` → 200.
2. Mac 1: Настройки → Синхронизация → подключить (токен первого устройства).
3. Mac 1: «Добавить Mac» → код. Mac 2: ввести код.
4. Правка на Mac 1 видна на Mac 2 не позже 10 с.
5. Отключить сеть на обоих, править один блок на обоих, вернуть сеть → появляется «Две версии», выбор расходится на оба Mac.
