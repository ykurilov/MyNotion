# Contract: Поведение редактора и клавиши

Пользовательский контракт приложения: что делает каждое действие. Источник для XCUITest.

## Быстрые символы в начале пустой строки (FR-009)

| Ввод | Результат |
|------|-----------|
| `# ` / `## ` / `### ` | заголовок 1 / 2 / 3 |
| `- ` или `* ` | маркированный список |
| `1. ` | нумерованный список |
| `[] ` или `[ ] ` | чекбокс |
| `/` | меню типов блоков с поиском по названию; Esc закрывает, оставляя `/` |

Символы и пробел работают в начале любого блока, как в Notion: в абзаце, заголовке, пункте списка, чекбоксе. Символы в текст не попадают. Вложенность пункта сохраняется, у заголовков её нет. Новый тип — не отмеченный чекбокс.

⌫ в начале блока не-абзаца превращает его в абзац; ⌫ в начале абзаца склеивает с предыдущим блоком.
Enter в пустом пункте списка или чекбоксе превращает его в абзац.

## Клавиши

| Клавиши | Действие |
|---------|----------|
| ⌘N | новая страница рядом с текущей; курсор сразу в названии, Enter из названия — в первый блок |
| ⇧⌘N | новая подстраница внутри текущей |
| ⇧⌘F | перейти в поле поиска страниц (FR-018): ввод сразу показывает выдачу под полем — сначала совпадения в названии, потом в тексте; ↑↓ — выбор, Enter — открыть, Esc — закрыть и очистить; уход из поля и уход приложения в фон закрывают выдачу. Слово ищется по началу, регистр не важен, «ё» = «е», корзина не ищется |
| ⌘B / ⌘I / ⌘U / ⇧⌘X / ⌘E | жирный / курсив / подчёркнутый / зачёркнутый / код |
| Tab / ⇧Tab | вложить / вынуть пункт списка или чекбокс (FR-008) |
| ⌥⇧↑ / ⌥⇧↓ | переставить блок выше / ниже (FR-011) |
| ⌘Enter | отметить / снять чекбокс |
| ⇧Enter | перенос строки внутри блока (FR-032); Enter — новый блок |
| ⌘Z / ⇧⌘Z | отмена / возврат (FR-012) |
| ⌘⌥S | показать / скрыть боковую панель |
| ⌘⇧E | выгрузить все записи в Markdown (FR-017) |

## Два режима выделения (как в Notion 7.38.1, проверено 15.10.2026)

- **Выделение текста** — мышью по тексту или ⇧+стрелками: полосы по тексту, и через несколько блоков тоже. Delete стирает выделенный текст, блоки склеиваются.
- **Выделение блоков** — блоки целиком. Включают: щелчок по «⋮⋮» (блок выделен и открыто его меню; Esc закрывает меню, блок остаётся выделенным), Esc при курсоре или выделенном тексте (выделяются блоки под ними), протяжка мышью с поля слева или справа от колонки (выделены блоки, которых коснулась полоса; щелчок на поле без протяжки — курсор в ближайшую строку).

| Клавиши в режиме блоков | Действие |
|---------|----------|
| ↑ / ↓ | выделить блок над / под выделенными |
| ⇧↑ / ⇧↓ | сузить или расширить выделение |
| Delete / ⌦ | удалить блоки целиком (одним шагом отмены) |
| ⌘C / ⌘X | копировать / вырезать блоки (в простом тексте — по строке на блок) |
| Tab / ⇧Tab, ⌥⇧↑ / ⌥⇧↓ | вложить, вынуть, переставить; блоки остаются выделенными |
| Enter | курсор в конец последнего выделенного блока |
| Esc | снять выделение, курсор в конец блока |
| буквы | ничего не меняют |

Щелчок в текст или выделение текста снимают режим блоков.

⌘K не используется. Ссылка: вставить адрес поверх выделенного текста или меню «Формат → Ссылка». ⌘F — системный поиск по открытой странице.

## Панель форматирования (FR-033, как в Notion 7.38.1)

- Всплывает у выделенного текста — внутри одного блока и через блоки — после того, как выделение закончено (мышь отпущена, ⇧+стрелки). Во время протяжки мышью её нет.
- Не появляется в режиме выделения блоков и без выделения. Прячется при наборе поверх выделения, Esc (выделение переходит в режим блоков), щелчке мимо, уходе фокуса из текста страницы и уходе приложения в фон. При прокрутке следует за выделением.
- Строка типа: значок и название типа выделенных блоков, у разных типов — «Разные типы». Щелчок открывает список тех же типов, что в меню «/», текущий отмечен галочкой; выбор меняет тип всех выделенных блоков, выделение и панель остаются. ↑↓, Enter, Esc в открытом списке — выбор, применить, закрыть только список.
- Кнопки (Notion 7.39, 002): цвет, жирный, курсив, подчёркнутый, «Tx»; ссылка, зачёркнутый, код, «√x», «⋯». «Tx» снимает с выделения оформление, ссылки и цвета (упоминания, даты, формулы остаются) одним шагом ⌘Z; «⋯» открывает меню блока, в котором начинается выделение, панель прячется. Кнопка оформления ставит его на всё выделение, а если оно уже есть у всего выделения — снимает (как ⌘B). Такая кнопка подсвечена синим значком. Ссылка открывает окно адреса, как «Формат → Ссылка». Панель после нажатия остаётся.
- Место — как у Notion (сверено вживую): карточка под строкой выделения, левым краем у указателя мыши — и при выделении мышью, и при ⇧+стрелках. Строка — та из первой и последней строк выделения, что ближе к указателю. Указатель не над страницей — у конца выделения. Внизу не помещается — над строкой. У края окна прижимается к нему.

## Иконка страницы (FR-034, как в Notion 7.38.1)

- У страницы без иконки при наведении на шапку над названием появляется серая «Добавить иконку»; щелчок ставит случайный эмодзи, как у Notion.
- Щелчок по иконке в шапке или в строке боковой панели открывает окно выбора под ней. Курсор сразу в поиске: ищет по русским и английским названиям (каждое слово — начало слова названия, «ё» = «е»). Без поиска — разделы: Недавние (последние 16 выбранных, на этом Mac), Смайлы и люди, Животные и природа, Еда, Занятия, Путешествия, Предметы, Символы, Флаги; значок внизу прокручивает к разделу.
- Щелчок по эмодзи или Enter (подсвеченный; стрелки двигают подсветку) ставит его и закрывает окно. «Случайная» ставит случайный и оставляет окно открытым. «Убрать» снимает иконку и закрывает окно. Esc, щелчок мимо и уход приложения в фон закрывают окно без изменений.
- Выбранное сразу видно в шапке, боковой панели, пути вверху и блоках-подстраницах; записывается одной правкой поля `icon` (с отметкой времени для синхронизации). ⌘Z возвращает прежнюю иконку, ⇧⌘Z — снова новую.

## Боковое дерево (FR-001…FR-006)

- Перетаскивание страницы на другую — внутрь; между страницами — рядом. Сброс страницы внутрь её же потомка запрещён (курсор «нельзя»).
- Двойной щелчок или Enter — переименовать. ⌘⌫ — в корзину.
- «Корзина» внизу панели: вернуть, удалить навсегда, очистить.
- Значок синхронизации внизу панели: готово / отправка / ошибка (FR-022); щелчок — подробности.

## Сообщения

- Ошибка записи: жёлтая полоса над страницей «Изменения не сохранены — <причина>. Повторяем…» (FR-015).
- Конфликт: блок с оранжевой меткой «Две версии», щелчок открывает сравнение и выбор (FR-021).
- Возврат страницы из корзины из-за правки на другом Mac: уведомление в окне.
