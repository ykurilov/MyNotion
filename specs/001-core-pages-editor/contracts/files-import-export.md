# Contract: Выгрузка в Markdown и импорт из Notion

## Выгрузка (FR-017, R12)

Юрий выбирает папку. Создаётся `MyNotion-выгрузка-<ГГГГ-ММ-ДД>/`:

```text
Проекты.md
Проекты/
├── MyNotion.md
└── MyNotion/
    └── Идеи.md
Дневник.md
```

| Блок | Markdown |
|------|----------|
| paragraph | текст |
| heading1…3 | `#`, `##`, `###` |
| bulletItem / numberedItem | `- ` / `1. `, отступ 2 пробела на уровень |
| checkbox | `- [ ] ` / `- [x] ` |
| pageLink | `[Название](Папка/Название.md)` |
| bold / italic / strikethrough / code / link | `**…**` / `*…*` / `~~…~~` / `` `…` `` / `[…](url)` |
| underline (FR-033) | `<u>…</u>` — в Markdown своего подчёркивания нет |
| перенос строки внутри блока (`\n` в тексте, FR-032) | конец строки с двумя пробелами (`строка␠␠⏎`); следующая строка пункта — с отступом его текста |

Недопустимые в именах файлов символы (`/`, `:`) заменяются на `-`. Одинаковые имена соседей получают ` (2)`, ` (3)`.
Страницы в корзине не выгружаются.

## Импорт из Notion (FR-025…FR-027, R11)

**Вход**: ZIP «Export → Markdown & CSV» из Notion (включая вложенные ZIP в большом экспорте) или распакованная папка.

**Правила**:
- Файл `Название <32 hex>.md` → страница «Название». Папка `Название <32 hex>/` → её подстраницы.
- Поддерживаемое (как в таблице выгрузки выше) переносится в блоки.
- Таблицы `.csv` → страница с абзацами «Колонка: значение» по строкам.
- Картинки и вложения → абзац «[файл: имя]»; сами файлы не копируются.
- Toggle, callout, цитаты, код-блоки, встраивания → абзацы с исходным текстом.
- Ссылки между страницами Notion → блоки pageLink, если цель найдена в выгрузке; иначе простой текст.
- Всё попадает в новую ветку «Импорт из Notion — <дата>».

**Отчёт** после импорта: число страниц и блоков; список «страница — что упрощено».
Прерванный импорт откатывает недоделанную ветку; уже существующие записи не меняются.
