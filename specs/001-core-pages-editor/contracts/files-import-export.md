# Contract: Выгрузка в Markdown и импорт из Notion

## Выгрузка (FR-017, R12)

Юрий выбирает папку. Создаётся `MyNotion-выгрузка-<ГГГГ-ММ-ДД>/`:

```text
Проекты.md
Проекты/
├── MyNotion.md
└── MyNotion/
    └── Идеи.md
Дневник.md
```

| Блок | Markdown |
|------|----------|
| paragraph | текст |
| heading1…3 | `#`, `##`, `###` |
| bulletItem / numberedItem | `- ` / `1. `; вложенный пункт сдвинут на ширину маркера родителя (CommonMark): под `- ` — 2 пробела, под `1. ` — 3, под `10. ` — 4 |
| checkbox | `- [ ] ` / `- [x] `; вложенный под ним сдвинут на 2 пробела |
| pageLink | `[Название](Папка/Название.md)` |
| bold / italic / strikethrough / code / link | `**…**` / `*…*` / `~~…~~` / `` `…` `` / `[…](url)`; пересекающиеся и вложенные стили записываются так, что любая читалка видит то же оформление (см. ниже) |
| underline (FR-033) | `<u>…</u>` — в Markdown своего подчёркивания нет |
| перенос строки внутри блока (`\n` в тексте, FR-032) | конец строки с двумя пробелами (`строка␠␠⏎`); следующая строка пункта — с отступом его текста |

Недопустимые в именах файлов символы (`/`, `:`) заменяются на `-`. Одинаковые имена соседей (без учёта регистра) получают ` (2)`, ` (3)`.
Страницы в корзине не выгружаются.

Уточнения, принятые при реализации (T056):
- Заголовок страницы — первая строка файла: `# Название`; если у страницы есть иконка-эмодзи, она стоит перед названием: `# 📘 Название`. Пустое название — «Без названия».
- Стили на стыках: соседние отрезки с одинаковым оформлением сливаются, пустые знаки не пишутся, пробелы на краю отрезка стоят снаружи знаков (`**жирный** текст`). Если читалка по правилам CommonMark не примет `**`, `*` или `~~` (рядом буква или знак препинания, две серии звёздочек подряд, серия между знаками препинания), это оформление пишется тегом: `<strong>`, `<em>`, `<del>`. «!» перед ссылкой экранируется (`\!`), чтобы не вышла картинка. Проверено на 12 000 случайных сочетаний через commonmark.js и markdown-it.
- Нумерованный пункт получает свой номер в уровне (`1.`, `2.`, `3.`…), а не всегда `1.`; вложенный уровень начинает счёт заново.
- Пустой абзац — пустая строка между блоками; хвостовые пустые строки страницы отбрасываются.
- Путь в `pageLink` записывается относительно файла страницы (`../Дневник.md`), пробелы и русские буквы кодируются (`%20`), скобки в названии экранируются.
- Ссылка на страницу из корзины или несуществующую остаётся простым текстом с названием.
- Служебные символы Markdown в тексте (`*`, `_`, `` ` ``, `[`, `~`, `<`, начало строки вроде `1.` или `#`) экранируются обратной косой чертой.
- Выгрузка атомарна: сначала всё пишется во временную скрытую папку рядом, затем она переименовывается. При ошибке или отмене следов не остаётся. Повторная выгрузка в тот же день получает имя `MyNotion-выгрузка-<дата> (2)`.
- Команда меню «Файл → Выгрузить в Markdown…» (⌘⇧E): окно выбора папки, выгрузка в фоне, в конце — уведомление с кнопкой «Показать в Finder». Служебный флаг `--export-markdown <папка>` делает то же без окна.

## Импорт из Notion (FR-025…FR-027, R11)

**Вход**: ZIP «Export → Markdown & CSV» из Notion (включая вложенные ZIP в большом экспорте) или распакованная папка.

**Правила**:
- Файл `Название <32 hex>.md` → страница «Название». Папка `Название <32 hex>/` → её подстраницы.
- Поддерживаемое (как в таблице выгрузки выше) переносится в блоки.
- Таблицы `.csv` → страница с абзацами «Колонка: значение» по строкам.
- Картинки и вложения → абзац «[файл: имя]»; сами файлы не копируются.
- Toggle, callout, цитаты, код-блоки, встраивания → абзацы с исходным текстом.
- Ссылки между страницами Notion → блоки pageLink, если цель найдена в выгрузке; иначе простой текст.
- Всё попадает в новую ветку «Импорт из Notion — <дата>».

**Отчёт** после импорта: число страниц и блоков; список «страница — что упрощено».
Прерванный импорт откатывает недоделанную ветку; уже существующие записи не меняются.

Уточнения, принятые при реализации (T083–T090):
- Notion 7 (проверено на 7.38.1) пишет хвост `<32 hex>` только у файлов, папки подстраниц — без него (`Страница <hex>.md` + `Страница/`). Notion постарше и наша выгрузка тоже читаются: папка ищется сначала по полному имени файла, потом по названию без хвоста. Папка без своей страницы (обёртка «Private & Shared», корень архива) прозрачна: её страницы встают уровнем выше.
- Notion не выгружает иконки страниц. Иконкой становится эмодзи в начале строки названия (`# 📘 Название`) — так пишет наша выгрузка.
- Строки блока подряд без пустой строки — один блок с переносами (`\n`), с двумя пробелами в конце или без: Notion переносы внутри блока пишет простым переводом строки. Лишняя пустая строка между блоками — пустой абзац.
- Вложенность списков — по колонке текста родителя: у Notion по 4 пробела, у нашей выгрузки по ширине маркера. После `- [ ]` у Notion два пробела — в текст не попадают.
- Порядок подстраниц — порядок ссылок на них в родителе; подстраница без ссылки получает блок pageLink в конце родителя. Строка из одной ссылки на страницу выгрузки (`.md`, `.csv` или адрес notion.so с её id) — блок pageLink, даже если это не подстраница; ненайденная — абзац с названием. Такая же ссылка внутри текста — просто текст (адрес notion.so остаётся ссылкой).
- У базы данных Notion два CSV: вид и полная таблица `_all.csv`; берётся полная. Строка таблицы — один абзац, «Колонка: значение» через перенос; страницы строк — подстраницы таблицы. Таблица Markdown (`| a | b |`) упрощается так же.
- Тексты упрощённого: цитата, выноска (`<aside>`), переключатель (`<details>`, `<summary>` — отдельный абзац), формула (`$$`), блок кода — абзац с исходным текстом без оформления; разделитель `---` пропускается; встраивание (`<iframe>`, `<figure>`…) — абзац с текстом или адресом. Картинка и ссылка на вложение — «[файл: имя]» прямо в строке. Всё это перечисляется в отчёте по страницам.
- Оформление в строке разбирается по правилам CommonMark и GFM, как его пишет выгрузка: круговой тест «наша выгрузка → разбор → те же блоки» прогоняет 2 000 случайных страниц с пересекающимся оформлением.
- Запись — короткими транзакциями (до 1 000 блоков, страница целиком в одной): правка открытой страницы ждёт не дольше одной транзакции. Ветка и строка журнала `import_run` (running) появляются первой транзакцией; ошибка или «Остановить» стирают ветку и ставят failed; после падения приложения ветку стирает следующий запуск. 1 000 страниц и 147 000 блоков — 8,5 с (Mac Studio M4 Max, Release).
- Отпечаток выгрузки — SHA-256 путей (в одной форме Юникода) и содержимого всех файлов: ZIP и та же выгрузка в папке дают один отпечаток. Повтор удачного импорта — вопрос до начала («Импортировать ещё раз» или «Отмена»); неудачный повтором не считается.
- Команда «Файл → Импорт из Notion…»: окно выбора ZIP или папки (кнопка «Перенести»), ход — карточкой внизу окна «Перенесено страниц: N из M» с «Остановить», в конце — окно итога поверх страницы с «Открыть страницу» и синей «Готово». Повтор — окно «Этот файл из Notion уже переносили» с «Отмена» и синей «Перенести ещё раз». Служебный флаг `--import-notion <путь>` делает то же без окна.
