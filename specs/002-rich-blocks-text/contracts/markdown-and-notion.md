# Contract: Выгрузка в Markdown и импорт из Notion — новые блоки

Дополняет [001 files-import-export](../../001-core-pages-editor/contracts/files-import-export.md). Правила экранирования, имён файлов и атомарности выгрузки — оттуда.

## Выгрузка (FR-117)

Принцип: что есть в Markdown — пишется Markdown; чего нет — HTML-тегом, как пишет Notion. Свои атрибуты — `data-…`: их не видит читалка Markdown, а наш импорт по ним восстанавливает блок без потерь (SC-105).

### Блоки

| Блок | Запись |
|------|--------|
| Переключатель | `<details>` / `<summary>текст</summary>`, пустая строка, дети Markdown, пустая строка, `</details>`. Свёрнутость не пишется |
| Цитата | `> текст`; дети — строками `> ` с отступом их Markdown |
| Выноска | `<aside data-icon="💡">`, пустая строка, текст и дети Markdown, `</aside>` |
| Разделитель | `---` |
| Код | ```` ```swift ```` … ```` ``` ````; язык `plain` — без названия; внутри три «`» подряд — ограда из четырёх |
| Формула-блок | `$$`, запись, `$$` |
| Оглавление | `<nav data-toc></nav>` |
| Картинка | `![подпись](Страница/имя.png)`; ширина не 100 % — `<img src="Страница/имя.png" alt="подпись" data-width="0.6">` |
| Файл | `[имя.pdf](Страница/имя.pdf)` отдельной строкой |
| Видео — файл | `<video src="Страница/имя.mp4" controls></video>`, подпись — строкой под ним |
| Видео — YouTube, Vimeo | `<iframe src="адрес встраивания" data-video="youtube"></iframe>`, на строке под ним — обычная ссылка на адрес ролика |
| Закладка | `<a href="адрес" data-bookmark>заголовок или адрес</a>`, описание — строкой под ним курсивом |
| Таблица | таблица GFM; первая строка — шапка всегда (так требует GFM). Без строки заголовков или со столбцом заголовков — перед таблицей `<!-- mynotion:table header-row="false" header-column="true" -->`. В ячейке `|` экранируется, перенос — `<br>` |
| Колонки | `<div data-columns>`, на колонку `<div data-column data-width="0.5">`, пустая строка, блоки Markdown, пустая строка, `</div>`, … `</div>` |
| Цвет блока | перед блоком строка `<!-- mynotion:color text="red" background="yellow" -->` |

### В строке

| Оформление | Запись |
|------------|--------|
| Цвет текста | `<span data-color="red">текст</span>` |
| Цвет фона | `<mark data-color="yellow">текст</mark>` |
| Оба | вложенные: `<mark data-color="yellow"><span data-color="red">текст</span></mark>` |
| Упоминание страницы | ссылка на файл страницы, как `pageLink` 001: `[📘 Название](../Название.md)`; страница не выгружена — название простым текстом |
| Дата | `<time datetime="2026-10-20T09:00+08:00">20 октября 2026, 9:00</time>`; с напоминанием — `data-remind="2026-10-20T08:00:00Z"` |
| Формула в строке | `$запись$`; рядом цифра или `$` в записи — `<span data-equation>запись</span>` |

### Файлы

- Копии вложений лежат в папке страницы `Название/` (та же папка, что у подстраниц); имена — по правилам `ExportFileNames` 001, совпадение с подстраницей или другим файлом получает « (2)».
- Файл, ещё не скачанный на этот Mac, не выгружается: вместо него строка `[файл не скачан: имя.pdf]`; итог выгрузки сообщает «Не выгружено файлов: N — они ещё не скачались с сервера».
- Выгрузка ждёт копирования всех файлов и остаётся атомарной (001).

## Импорт выгрузки MyNotion

Всё из таблиц выше читается обратно в те же блоки и оформление. Круговая проверка: эталонная «богатая» страница → выгрузка → импорт → те же блоки, текст, оформление, файлы (сверка SHA-256), без упрощений (SC-105). Свёрнутость и сделанность напоминаний не переносятся (их нет в выгрузке).

## Импорт из Notion «Markdown & CSV» (FR-118)

| В выгрузке Notion | Становится |
|-------------------|------------|
| `<details>` / `<summary>` | переключатель с детьми |
| `<aside>` с эмодзи в начале | выноска с этой иконкой |
| `> текст` | цитата |
| `---` | разделитель |
| ```` ```язык ```` | код с этим языком; незнакомый язык — `plain`, имя языка в отчёт |
| `$$ … $$`, `$…$` | формула-блок, формула в строке |
| таблица Markdown `| a | b |` | таблица; первая строка — строка заголовков |
| `![](Страница/картинка.png)` | картинка; файл копируется из выгрузки во вложения |
| `[имя](Страница/файл.pdf)` на своей строке | файл; копируется |
| ссылка на YouTube или Vimeo на своей строке | видео; обложка запрашивается после импорта в фоне, без интернета — карточка с адресом |
| прочая ссылка на своей строке | закладка с адресом; данные карточки не запрашиваются, «Обновить» — по желанию |
| `[Название](Страница%20id.md)` внутри текста | упоминание страницы, если она есть в выгрузке; иначе ссылка 001 |
| `@20 октября 2026` и даты вида `@October 20, 2026` | дата без напоминания |

- Файл больше 100 МБ или не найден в выгрузке — абзац «[файл: имя]», как в 001, и строка в отчёте.
- Таблицы баз данных (`.csv`) — как в 001: таблицы-базы — отдельная спецификация.
- **В выгрузке Notion «Markdown & CSV» нет цветов и колонок** (содержимое колонок Notion пишет подряд), нет оглавления и напоминаний. Текст переносится полностью, отчёт пишет «Цвета и колонки Notion в Markdown не выгружает». Решение Юрия 19.10.2026: так и остаётся, импорт HTML-выгрузки не делается (research R14). Этап 7 проверяет таблицу на живой выгрузке Notion Юрия и правит её по факту.
- Отчёт импорта (001) перечисляет только то, что действительно упрощено.
