# Contract: синхронизация v4, выгрузка и импорт

Основа — `../003-pages-navigation/contracts/sync-v3-and-export.md`. Сервер не меняется: он хранит зашифрованные пачки и файлы и содержимого не знает.

## Пачка

- `formatVersion`: 4. Mac с форматом 3 пачку v4 не применяет, ждёт и показывает «Обновите MyNotion на этом Mac». Пачки v1–v3 читаются.
- Все новые изменения — того же вида `{entity, id, pageId?, field, value, hlc}`; у каждого поля своя метка, применяется более поздняя.

## Новые сущности

| entity | id | pageId | field → value |
|--------|----|--------|---------------|
| `database` | страница-база | она же | `isInline` → bool; `defaultTemplateId` → UUID? ; `erased` |
| `property` | id свойства | страница-база | `name` → текст; `typeAndConfig` → `{type, config}`; `sortKey` → строка; `deletedAt` → дата?; `erased` |
| `option` | id варианта | страница-база | `name`; `color`; `placement` → `{propertyId, sortKey, statusGroup?}`; `deletedAt` |
| `view` | id вида | страница-база | `name`; `type`; `sortKey`; `filter`; `sorts`; `columns`; `group`; `layoutOptions` (JSON как в data-model.md) |
| `cell` | id строки | страница-база | `value` → `{propertyId, value}` (`value: null` — пусто) |
| `relationLink` | id связи (UUID v5) | страница-база | `link` → `{propertyId, rowId, targetRowId}` (один раз, при создании); `isPresent` → bool; `sortKey` |
| `rowOrder` | UUID v5 из `(viewId, rowId)` | страница-база | `sortKey` → `{viewId, rowId, sortKey}` |

- `cell`: ключ слияния — `(id строки, propertyId)`; у каждой ячейки своя метка. Ячейка свойства, которого здесь ещё нет, хранится и показывается, когда придёт свойство.
- `relationLink` без пришедшей строки-цели хранится; связь показывается, когда строка придёт.
- `option` удалённый (`deletedAt`) — значения ячеек с ним не трогаются; ячейка показывает вариант пустым, ⌘Z или возврат варианта показывает снова.
- Блок `database` — новое значение `kind` (формат v4); Mac с форматом 3 такие пачки не применяет (см. выше).
- Снимок для нового Mac (002) содержит все новые сущности.

## Не передаётся

`db_computed`, `sortText`, `sortNumber`, `searchText`, строки `search_index` и индекса напоминаний по ячейкам — выводятся на каждом Mac.

## Выгрузка базы

Рядом со страницей, где база (полностраничная — как подстраница 001; встроенная — в папке хозяина):

```text
Задачи.csv                     # все строки, все неудалённые свойства
Задачи/
├── Позвонить в банк.md        # строка: «# Название», свойства, тело
├── Позвонить в банк/          # подстраницы строки и файлы, как у страницы 001
└── …
Задачи.mynotion-database.json  # схема для обратного импорта
```

**CSV** (как `_all.csv` Notion 7.39 — сверка, visual-reference/notion-survey.md, раздел 11):
- UTF-8 с BOM, запятая, кавычки RFC 4180; первая колонка — название; дальше свойства в порядке первого вида; колонки скрытых свойств тоже.
- Значения: число — без разделителей групп, точка (`1234.5`); процент — `12%`; валюта — число; дата — как у Notion (`October 21, 2026`, `October 21, 2026 3:15 PM`, диапазон `… → …`); флажок — `Yes` / `No`; множественный выбор и файлы — через `, `; связь — `Название (Задачи/Название.md)` через `, ` (относительный путь к файлу строки, вместо ссылки app.notion.com); формула и сводка — итог текстом; ID — `ПРЕФИКС-12`; создано / изменено — как дата со временем.

**Markdown строки**: `# Название`, затем строки `Свойство: значение` (как у Notion), пустая строка, тело по правилам 001–003.

**Схема** `*.mynotion-database.json`: `formatVersion`, свойства с типами и config, варианты с цветами и группами, формулы, связи (цель — по относительному пути выгрузки цели), виды, шаблоны (как страницы в папке `Задачи/Шаблоны/`), соответствие строк файлам. Импорт MyNotion по ней возвращает базу целиком; без неё — читает CSV как выгрузку Notion.

## Импорт выгрузки Notion «Markdown & CSV»

Обход папок 001 уже находит `Задачи <id>.csv` (вид: только его колонки) и `Задачи <id>_all.csv` (все свойства, включая скрытые) — берётся `_all`; порядок колонок `.csv` вида — порядок колонок вида после импорта, остальные свойства — скрытые. Дальше:

1. **Место**: ссылка на CSV в `.md` страницы-хозяина — встроенная база на месте ссылки; иначе — полностраничная подстраница.
2. **Строки**: строка CSV ↔ файл `Название <id>.md` в папке `Задачи/` (выгрузка с «Include subpages») по названию и порядку; у одинаковых названий — разные 32 hex. В `.md`: `# Название`, пустая строка, строки `Свойство: значение` (только непустые), дальше тело — оно идёт блоками 001–003, строки свойств отрезаются. Выгрузка без «Include subpages» (только два CSV) — строки без тел, отчёт это называет.
3. **Типы** — по всем непустым значениям столбца, по порядку, первый подходящий целиком:

| Признак | Тип |
|---------|-----|
| первая колонка | Название |
| все `Yes` / `No` | Флажок |
| все — число (с `%` — процент; со знаком валюты — валюта) | Число |
| все — дата или дата со временем в форматах Notion, или диапазон `… → …` | Дата |
| все — разные целые 1…N, столбец назван `ID` (или `ПРЕФИКС-N` с одним префиксом) | ID |
| все — `http(s)://…` | Ссылка |
| все — адрес почты | Email |
| все — телефон (цифры, `+`, пробелы, скобки, дефисы; ≥ 7 цифр) | Телефон |
| все — `Название (https://app.notion.com/p/<32 hex>?pvs=21)` (в CSV) или `Название (относительный путь <32 hex>.md)` (в `.md`) на строки баз этой же выгрузки — по 32 hex | Связь (односторонняя; есть столбец-пара во второй базе — двусторонняя) |
| значения через `, `, различных ≤ 50 и повторяются | Множественный выбор |
| различных ≤ 50 и в среднем повторяются ≥ 2 раз, без запятых | Выбор |
| иначе | Текст |

   Столбцы с названиями `Created time`, `Created`, `Создано` / `Last edited time`, `Изменено` и датами со временем — даты создания и правки строки (`createdAt`, `updatedAt` страницы) и свойства «Создано» / «Изменено».
   Цвета вариантов — по порядку цветов Notion по кругу. Статус неотличим от выбора — становится «Выбором».
4. **Отчёт** импорта (окно 001) — по каждой базе: угаданные типы, связи, «стали значениями: Итог (формула), Часы (сводка)» (если в выгрузке они отличимы — нет: такие столбцы видны как число или текст, отчёт пишет «формулы и сводки Notion приходят готовыми значениями»), «цвета вариантов, виды, фильтры, сортировки и шаблоны в выгрузке Notion не передаются», «люди → текст».

## Импорт со схемой из Notion по ключу (Q3, ждёт подтверждения Юрия)

- Ключ «внутренней интеграции» Notion хранится в Связке ключей; окно импорта предлагает «Дочитать схему из Notion» и показывает, как дать интеграции доступ к страницам.
- Только чтение: `GET /v1/databases/{id}` и `GET /v1/data_sources/{id}` (id — 32 hex из имён файлов выгрузки), без записи и без чтения строк.
- Из схемы берутся: точные типы, форматы чисел, варианты с цветами, группы статусов, формат даты, связи (с парой), сводки (связь, свойство, вычисление), формулы (выражение переводится в язык MyNotion; не поддержанное — значение и строка отчёта), префикс ID.
- Нет сети, нет ключа, нет доступа к базе — эта база импортируется по CSV, отчёт называет причину.
