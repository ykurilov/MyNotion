# Contract: вид и клавиши баз данных

Образец — Notion 7.39 (снимки и описание — `../visual-reference/`, `notion-survey.md`, сверка 21.10.2026, тёмная тема). Цифры с «≈» — предварительные: этап, вводящий часть, снимает их с настоящего Notion (FR-337) и правит здесь. Масштаб снимков: 1 px ≈ 1,26 pt.
Всплывающие окна и меню — общий вид `PopupSurface` 002; меню собираются из описателей «файл на пункт» (реестры этапа 0).

## Полностраничная база (`notion-table-clean.png`)

```
Путь / … / Задачи                                                   ☆  •••   ← верхняя полоса 001–003
Задачи                                                                       ← название базы (как название страницы)
[▦ Таблица] [▦ Работа] [+]          [⏷] [⇅] [🔍] [⚙]  [Создать ▾]            ← строка вида
[Статус: не Готово ▾] [⇅ 2 сортировки ▾] [+ Фильтр]                          ← полоса фильтров (когда показана)
Aa Название │ # Число │ ◉ Выбор │ 📅 Срок │ ✳ Статус │ + │ •••               ← шапка колонок
▯ Купить молоко │       │         │        │ ● Не начато │
+ Новая строка
                КОЛИЧЕСТВО 5                                                 ← итоги (Q1), когда выбраны
```

- Иконка и обложка базы — как у страницы 003; описания базы нет (Assumptions).
- Строка видов: вкладка вида — иконка вида и название, активная — с фоном-плашкой (≈ 30 pt высотой); «+» — новый вид (в 004 только «Таблица»). Меню вкладки (`notion-view-tab-menu.png`): Переименовать, Изменить вид, Дублировать вид, Удалить вид (нет при одном виде). «Дублировать» создаёт «Таблица (1)» и открывает настройки вида с выделенным именем.
- Справа: Фильтр (воронка), Сортировка (⇅), Поиск (лупа), ⤢ (только у встроенной — открыть на всё окно), «Настройки вида» (ползунки), синяя «Создать ▾». Кнопки Automations и AI Autofill Notion — не делаются. Активные фильтр и сортировка — значки синие.
- Шапка колонок: иконка типа и название серым; у «Название» — `Aa`. В конце шапки «+» (новое свойство) и «•••» (настройки вида). Ширина по умолчанию: «Название» ≈ 280, остальные ≈ 200; наименьшая ≈ 100 (≈ — снять в US1). Числа выровнены вправо.
- Тёмная тема: фон страницы, линии сетки — цвет линий 003 (≈ 0x2C2C2B), шапка — серым текстом панели; светлая — те же места палитры (≈).

## Встроенная база (`notion-inline-db-new.png`, `notion-inline-view-settings.png`)

- Название серым крупным полужирным над таблицей (новая — «Новая база» серым-подсказкой); с одним видом вкладка вида не видна; кнопки справа те же плюс ⤢.
- Таблица во всю ширину колонки текста страницы (широкая страница 003 — шире); не влезающие колонки — прокрутка вбок внутри блока.
- Под строками — «Загрузить ещё» (≈ надпись Notion «Load more»), если строк больше предела загрузки.
- Блок ведёт себя как блок 002: ручка «⋮⋮», меню блока (удалить, дублировать, переместить, «Открыть на всё окно»), выделение и перенос.

## Строки

- Высота строки ≈ 33 pt (`notion-cell-selected.png`); с переносом текста (Q1) — по содержимому.
- При наведении (≈, `notion-row-hover-open-handle.png`): слева «+» (новая строка ниже) и «⠿» (тянуть; щелчок — меню строки), у названия справа кнопка «ОТКРЫТЬ». Флажок выбора — у левого края при наведении.
- Выбранные флажками строки — полоса над таблицей «N выбрано │ Дублировать │ 🗑 │ •••» (быстрые кнопки свойств Notion — не делаются).
- Меню строки (правый щелчок, `notion-row-context-menu.png`): поле «Найти действие…»; В избранное; Изменить иконку; Изменить свойство ›; Открыть в › (Новой вкладке ⇧⌘↩, Новом окне, Сбоку ⌥-щелчок); Дублировать ⌘D; Переместить в ⇧⌘P; Удалить в корзину ⌫; внизу серым «Изменено …, N слов». Copy link, Comment, Archive — не делаются.
- «+ Новая строка» внизу (и у каждой группы): строка в конце, курсор в названии, Enter — готово, ячейка остаётся выбранной.
- «Создать»: новая строка вверху вида по шаблону по умолчанию, открывается способом вида (по умолчанию — сбоку), значения фильтра подставлены (`notion-new-row-side-peek-filtered.png`).

## Ячейки и клавиши

| Действие | Что делает |
|----------|------------|
| Щелчок по ячейке названия, текста, числа, ссылки, email, телефона | правка на месте |
| Щелчок по ячейке выбора, статуса, даты, связи, файлов | окно правки ячейки под ней |
| Щелчок по флажку | переключить |
| Esc в правке | выход, ячейка выбрана (синяя рамка ≈ 1,5 и точка в углу) |
| Esc на выбранной ячейке | выбрана строка |
| Ввод буквы на выбранной ячейке | правка с заменой содержимого |
| Enter на выбранной ячейке / в правке | правка / готово и ячейка ниже |
| ↑ ↓ ← →, Tab, ⇧Tab | по ячейкам |
| ⇧-стрелки, ⇧-щелчок, протяжка | прямоугольник ячеек |
| ⌘C / ⌘X / ⌘V | копировать / вырезать / вставить таблицей (табуляции и переводы строк; к тексту — ещё простая таблица HTML для Numbers) |
| ⌫ | стереть выбранные ячейки (у названия — пустое название) |
| ⌘A на выбранной ячейке | все ячейки вида |
| ⌘Z / ⇧⌘Z | отмена / возврат любой правки базы и вида |
| ⌥-щелчок по строке | открыть сбоку |
| ⇧⌘↩ на выбранной строке | открыть в новой вкладке |

Вставка за последнюю строку добавляет строки; за последнюю колонку — отбрасывается (Notion так же колонок не создаёт).

## Панель «Изменить свойство» (`notion-number-formats.png`, `notion-edit-property-*.png`)

Панель справа на высоту таблицы (≈ 280 шириной): «← Изменить свойство ×»; поле имени с иконкой; «Тип ›»; настройки типа (contracts/property-types.md); «Переносить текст» (Q1); «Дублировать свойство»; «Удалить свойство». Формула — «Изменить формулу ⌄» открывает редактор (contracts/formulas.md, `notion-formula-editor-result.png`). Связь — «Связана с» (серым, не меняется), «Лимит», «Ответное свойство» (переключатель, по умолчанию выключен) с полем имени. Сводка — «Связь», «Свойство», «Вычислить» и надпись «Изменения применяются ко всем видам с этим свойством».
Окно «Свойства» базы (из настроек вида) — список свойств с ручками, «+ Новое свойство» и (сверх Notion) раздел «Удалённые свойства» с «Вернуть» и «Удалить навсегда».

## Добавление свойства (`notion-add-property-inline.png`, `notion-property-types-*.png`)

«+» в шапке: в шапке появляется поле «Название свойства…», под ним окно «Тип» с поиском и типами в две колонки (contracts/property-types.md, «Список типов»). Выбор создаёт колонку справа.

## Настройки вида (`notion-view-settings-panel.png`)

Панель справа (как «Изменить свойство»): поле имени вида; Раскладка ›; Видимость свойств [N] ›; Фильтр ›; Сортировка ›; Группировка ›; — ; Свойства › (окно «Свойства» базы). Остальные пункты Notion (Conditional color, Copy link, Source, Automations, AI, Turn into, View archived pages, More settings, Manage data sources, Lock database) — не делаются.
- **Раскладка** (`notion-layout-settings.png`): плитки типов видов (в 004 — одна «Таблица»; 005 добавит свои); «Переносить весь текст» (выкл, Q1); «Открывать строки» › Сбоку («Открывает страницы сбоку, вид позади остаётся рабочим» — по умолчанию для таблицы) / По центру («Открывает страницу в окне по центру») / На всю страницу; «Предел загрузки» › 10 / 25 / 50 ✓ / 100 (только у встроенной ≈ — Notion показывает и у полностраничной; там предела нет, прокрутка всей базы).
- **Видимость свойств** (`notion-view-property-visibility.png`): поиск; «Показаны в таблице» + «Скрыть все»; «Скрыты в таблице» + «Показать все»; у строки ручка (порядок колонок) и глаз; «Название» не скрывается.
- **Фильтр**, **Сортировка** — те же окна, что у кнопок (contracts/property-types.md).
- **Группировка** (`notion-group-settings.png`): «Группировать по ›» (Нет ✓ и свойства, кроме ID и файлов); «Сортировка» › Вручную ✓ / По алфавиту / В обратном порядке; у даты и числа — шаг; «Скрывать пустые группы» (вкл); «Группы» + «Скрыть все», у группы ручка и глаз; «Убрать группировку».

## Группы в таблице

Заголовок группы: «▾» (свернуть), цветная плашка варианта (или текст), число строк серым; строки группы; «+ Новая строка» группы; итоги группы (Q1). Внизу таблицы — «+ Новая группа» (у выбора и статуса — новый вариант).

## Поиск в базе (`notion-search-in-database.png`)

Лупа раскрывает поле в строке вида; таблица сужается с каждым символом, найденное подсвечено серой плашкой; «×» очищает и сворачивает.

## Страница строки (`notion-row-full-page-top.png`, `notion-new-row-side-peek-filtered.png`)

- Шапка страницы 003 (иконка, обложка), название; под ним свойства: слева иконка типа и имя серым (≈ 160 шириной), справа значение (правка как в ячейке), пустое — «Пусто» серым; «+ Добавить свойство». Порядок — как у свойств базы (`sortKey`).
- Ниже — тело страницы; пустое тело показывает «Нажмите Enter, чтобы продолжить с пустой страницей, или выберите шаблон» и строки шаблонов базы (места 003 `TemplateRows`). Комментариев нет.
- **Сбоку**: панель справа на высоту окна (≈ 45 % ширины окна, ≈ — снять в US1), сверху «»» (закрыть) и «⤢» (на всю страницу); вид таблицы слева рабочий. **По центру**: карточка ≈ 775×610 поверх затемнения, те же кнопки. Esc закрывает.
- Шаблон строки правится в карточке по центру с янтарной полосой сверху «Вы правите шаблон в «Задачи»».

## «Создать ▾» (`notion-new-dropdown-templates.png`)

Стрелка у «Создать» — окно «Шаблоны для «Задачи»»: строки «⠿ иконка Название •••»; «Пустая» с меткой «По умолчанию» (метка — у шаблона по умолчанию); «+ Новый шаблон». Без шаблонов — «Создайте шаблон страницы для этой базы» и «+ Новый шаблон». «•••» шаблона: Сделать по умолчанию, Изменить, Дублировать, Удалить («Повторять…» Notion — не делается).
В окне даты у шаблона — раздел «Быстрый выбор»: «Сейчас — время создания строки», «Сегодня — дата создания строки» (синие метки, `notion-template-date-shortcuts-picker.png`).

## «/» и меню страницы

- «/»: «База данных — встроенная», «База данных — на всю страницу» (поиск по «база», «database», «таблица»).
- Меню «•••» страницы-базы (003) получает «Выгрузить базу» (Markdown и CSV со схемой). Остальные пункты Notion (Merge with CSV, Lock database, Customize layout) — не делаются.
- Боковая панель: полностраничная база — строкой со значком таблицы (или своей иконкой), без стрелки раскрытия; встроенные базы и строки не видны.
- Поиск страниц (⌘P / ⌘K 001): строка — как страница, путь «Родитель / … / База».
