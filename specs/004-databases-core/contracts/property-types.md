# Contract: типы свойств

Для каждого типа: значение, показ, условия фильтра, сортировка, группировка, итоги колонки, сводка, смена типа. Названия — русские; в скобках — подпись Notion 7.39 для сверки. Порядок типов в списке «+» и «Сменить тип» — как в Notion (visual-reference/notion-survey.md, раздел 4) без невзятых.

## Список типов

Список «+» — поле «Название свойства…» в шапке и под ним «Тип» с поиском, типы в две колонки по строкам, как в Notion 7.39 (`visual-reference/notion-property-types-1.png`, `-2.png`). Порядок Notion без невзятых:

| Строка | Левая колонка | Правая колонка |
|--------|---------------|----------------|
| 1 | Текст (Text) | Число (Number) `#` |
| 2 | Выбор (Select) | Множественный выбор (Multi-select) |
| 3 | Статус (Status) | Дата (Date) |
| 4 | Файлы и медиа (Files & media) | Флажок (Checkbox) |
| 5 | Ссылка (URL) | Телефон (Phone) |
| 6 | Email (Email) | — |
| — | разделитель | |
| 7 | Связь (Relation) ↗ | Сводка (Rollup) |
| 8 | Формула (Formula) Σ | ID (№) — серый, если в базе уже есть |
| — | разделитель | |
| 9 | Создано (Created time) | Изменено (Last edited time) |

Название (Title, `Aa`) — только первая колонка, в списке нет. Иконки — как у Notion (снимки). Новая колонка создаётся сразу; окно настроек — «Изменить свойство» в меню колонки (у связи и сводки — сразу, без них свойство пустое).

Не берутся: Person, Created by, Last edited by, Button, Place, Verification, «AI Autofill», файлы Google Drive, Figma, GitHub, Zendesk (spec, Assumptions).

## Значения и показ

| Тип | Показ в ячейке | Правка |
|-----|----------------|--------|
| Название | текст + иконка страницы, если есть; кнопка «Открыть» при наведении | на месте; Enter — открыть строку при не пустом |
| Текст | одна строка с «…» (с переносом — целиком, Q1) | на месте, ⇧Enter — перенос строки, оформление 002 |
| Число | по формату; «полоса» / «кольцо» с числом или без | на месте, только число; формат ввода — язык macOS или точка |
| Выбор, Статус | цветная плашка | список с поиском, Enter создаёт (у статуса — в «Не начато») |
| Множественный выбор | плашки через пробел, лишние обрезаются | тот же список, выбор нескольких, ⌫ снимает последний |
| Дата | по формату даты и времени; диапазон «начало → конец»; колокольчик при напоминании | окно календаря |
| Файлы и медиа | имена файлов плашками; картинка — уменьшенная | окно «Загрузить» / «Ссылка» |
| Флажок | квадрат с галочкой | щелчок, пробел |
| Ссылка, Email, Телефон | текст; кнопка открыть / написать / позвонить при наведении | на месте |
| Формула | итог по его типу | — (настройка — редактор формулы) |
| Связь | названия строк цели с иконками | окно поиска строк цели |
| Сводка | итог (число, дата, список плашек — по вычислению) | — |
| Создано, Изменено | дата и время по формату свойства | — |
| ID | `ПРЕФИКС-N` или `N` | — |

## Число: форматы

Окно «Формат числа» с полем «Фильтр форматов…» (`visual-reference/notion-number-formats.png`): `number` (Число), `numberWithSeparators` (Число с разделителями), `percent` (Процент), затем валюты в порядке Notion 7.39 с кодом в скобках: доллар США (USD), австралийский (AUD), канадский (CAD), сингапурский (SGD), евро (EUR), фунт (GBP), иена (JPY), рубль (RUB), рупия (INR), вона (KRW), юань (CNY), реал (BRL), лира (TRY), рупия Индонезии (IDR), франк (CHF), гонконгский доллар (HKD), новозеландский доллар (NZD), дальше — по снимку прокрутки в US2: крона (Швеция), норвежская крона, мексиканское песо, рэнд, новый тайваньский доллар, датская крона, злотый, бат, форинт, чешская крона, шекель, чилийское песо, филиппинское песо, дирхам, колумбийское песо, риял, ринггит, лей, аргентинское песо, уругвайское песо, перуанский соль.
`decimals`: «По умолчанию» или 0…8 (≈ по сверке). «Показывать как»: Число / Полоса / Кольцо; у полосы и кольца — цвет (10 цветов Notion), «Разделить на» (по умолчанию 100) и «Показывать число».

## Дата: форматы и напоминания

- Формат даты (по умолчанию «Полный»): Полный (`21 октября 2026`), Короткий (`21.10.2026` ≈), Месяц/День/Год, День/Месяц/Год, Год/Месяц/День, Относительный (Сегодня, Вчера, Завтра, иначе полный).
- Время: 12 часов, 24 часа, Скрыть. Часовой пояс — системный (≈ Notion показывает пояс; один пользователь — не берётся).
- Напоминания — без времени: Нет, В день события (9:00), За 1 день (9:00), За 2 дня (9:00), За неделю (9:00); со временем: Нет, В момент события, За 5, 10, 15, 30 минут, за 1 час, 2 часа, за 1 день, за 2 дня. Список — по сверке (раздел 4).

## Цвета вариантов

`default` (по умолчанию), `gray`, `brown`, `orange`, `yellow`, `green`, `blue`, `purple`, `pink`, `red` — цвета фона плашки Notion 7.39 в светлой и тёмной теме (`VisualStyle`, значения со снимков). Новый вариант — случайный цвет, кроме цвета предыдущего.
Статус: «Не начато» — `default` («Not started»), «В работе» — `blue` («In progress»), «Готово» — `green` («Done»); группы «К выполнению» / «В работе» / «Завершено» (To-do / In progress / Complete).

## Условия фильтра

| Тип | Условия (Notion) |
|-----|------------------|
| Название, Текст, Ссылка, Email, Телефон | равно (Is), не равно (Is not), содержит (Contains), не содержит (Does not contain), начинается с (Starts with), заканчивается на (Ends with), пусто (Is empty), не пусто (Is not empty) |
| Число, ID | = ≠ > < ≥ ≤, пусто, не пусто |
| Выбор, Статус | равно, не равно, пусто, не пусто; значение — флажки вариантов, можно несколько (тогда «любой из» / «ни один из»), как окно фильтра Notion; у статуса ещё — группа (≈) |
| Множественный выбор | содержит, не содержит, пусто, не пусто |
| Дата, Создано, Изменено | равно (Is), до (Is before), после (Is after), не позже (Is on or before), не раньше (Is on or after), между (Is between), относительно сегодня (Is relative to today: прошлые / следующие / этот N дней, недель, месяцев, лет), пусто, не пусто; значение — Сегодня, Завтра, Вчера, Неделю назад, Через неделю, Месяц назад, Через месяц, Точная дата |
| Флажок | равно: отмечен / не отмечен (≈ — сверка не сняла) |
| Файлы и медиа | пусто, не пусто |
| Связь | содержит, не содержит, пусто, не пусто |
| Формула, Сводка | по типу итога (текст, число, флажок, дата); список — содержит / не содержит / пусто / не пусто |

Простой фильтр — чип «Свойство: значение ▾» под строкой вида; окно: «Свойство условие ▾», «•••» (Удалить фильтр, В расширенный фильтр), значение. Воронка синеет, пока есть фильтр; полоса чипов показывается после правки и прячется при новом открытии базы (как Notion).
Расширенный фильтр — чип «N правил ▾»: строки «Где [свойство] [условие] [значение] [•••]», вторая и дальше начинаются с «И ▾» / «Или ▾» — один на всю группу; «+ Добавить правило ▾» (правило или группа «чтобы вложить другие фильтры»); у строки «•••» — Удалить, Дублировать, Превратить в группу; «Удалить фильтр». Вложенность — до глубины Notion (≈ 2 уровня групп).
Новая строка при фильтре (FR-330): для условий «равно», «содержит», «отмечен», «равно дате» строка получает это значение; для остальных — пусто; при «ИЛИ» — значение первого условия.

## Сортировка

Окно: строки «⠿ [свойство ▾] [по возрастанию ▾] ✕» (у текста «А → Я / Я → А», у числа и даты «по возрастанию / по убыванию»), «+ Добавить сортировку», «Удалить сортировку» — снимает все уровни. Чип «↑ Свойство ▾», при нескольких «⇅ 2 сортировки».
Порядок значений: текст — по алфавиту языка macOS без учёта регистра; число, дата — по величине; выбор и статус — по порядку вариантов (как Notion); множественный выбор — по первому варианту; флажок — не отмечен < отмечен; связь — по названию первой связанной строки; пустые — всегда в конце.

## Группировка

| Тип | Группы |
|-----|--------|
| Выбор, Статус | по вариантам в их порядке (статус — ещё «по группам»), «Нет …» |
| Множественный выбор | строка в каждой группе своих вариантов |
| Флажок | Отмечен / Не отмечен |
| Дата, Создано, Изменено | по дню, неделе, месяцу, году (≈ Относительно: Сегодня, Прошлые 7 дней…), «Без даты» |
| Текст, Название, Ссылка, Email, Телефон | по точному значению или по первой букве (≈ по сверке) |
| Число | диапазоны: от, до, шаг |
| Связь | по связанным строкам |
| Формула | по типу итога |
Не группируются: ID, Файлы и медиа (как в Notion). Порядок групп: «Вручную» (перетаскивание), «По алфавиту», «В обратном порядке»; группа скрывается (глаз в списке групп, «Скрыть все»), сворачивается «▾»; «Скрывать пустые группы» включено по умолчанию; «Убрать группировку».

## Итоги колонки (Q1) и вычисления сводки

| Раздел | Вычисления (Notion) | Для типов |
|--------|----------------------|-----------|
| Показать | как есть (Show original), уникальные (Show unique values) — только сводка | все |
| Количество | всего (Count all), значений (Count values), уникальных (Count unique values), пустых (Count empty), не пустых (Count not empty) | все |
| Проценты | пустых (Percent empty), не пустых (Percent not empty) | все |
| Числа | сумма, среднее, медиана, мин, макс, размах (Sum, Average, Median, Min, Max, Range) | число, формула-число |
| Даты | ранняя, поздняя, диапазон (Earliest date, Latest date, Date range) | дата, создано, изменено |
| Флажок | отмечено, не отмечено, % отмеченных, % не отмеченных (Checked, Unchecked, Percent checked, Percent unchecked) | флажок |
Меню итога колонки — «Посчитать ›»: Нет ✓, Количество ›, Проценты › и по типу «Ещё ›» (числа, даты, флажок); итог — строкой под «+ Новая строка», мелкими заглавными («КОЛИЧЕСТВО 5»), под колонками без итога при наведении серое «Посчитать». Итог считается по строкам вида после фильтра и поиска; у каждой группы — свой.
Сводка: «Связь» → «Свойство» (все свойства связанной базы) → «Вычислить» с тем же набором; для числа ещё формат, знаки после запятой и «Показывать как»; внизу «Изменения применяются ко всем видам с этим свойством».

## Смена типа

| Из → в | Правило |
|--------|---------|
| любой → Текст | текст показа (как в CSV) |
| Текст → Число | число из текста (язык macOS или точка), иначе пусто |
| Текст → Выбор / Множественный выбор / Статус | варианты по значениям (у множественного — через запятую), цвета по кругу |
| Выбор ↔ Множественный выбор ↔ Статус | варианты переносятся (из множественного в выбор — первый); у статуса новые варианты — в «Не начато» |
| Текст → Дата | разбор дат Notion и ISO, иначе пусто |
| Текст / Число → Флажок | `Yes`, `true`, `1`, `да`, ненулевое — отмечен |
| Текст → Ссылка / Email / Телефон и обратно | значение как есть |
| любой → Связь, Сводка, Формула, Создано, Изменено, ID | значения не переносятся; прежние хранятся до ⌘Z |
| Связь → Текст | названия связанных строк через запятую |
Перед сменой прежние значения всех строк записываются в шаг отмены; ⌘Z возвращает их целиком (FR-318).
