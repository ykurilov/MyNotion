# Contract: формулы

Язык — подмножество формул Notion 2.0 (язык Notion с 2023 года; в 7.39 тот же). Формула, написанная в Notion из этого подмножества, в MyNotion даёт тот же итог. Всё остальное — ошибка «Функция … не поддерживается в MyNotion».

## Значения

| Тип | Что это | Пустое |
|-----|---------|--------|
| число | 64-битное с плавающей точкой | пусто |
| текст | строка | `""` |
| флажок | `true` / `false` | `false` |
| дата | момент или диапазон (`dateStart`, `dateEnd`), с временем или без | пусто |
| список | значения одного типа | `[]` |
| страница | строка базы (элемент списка из связи) | — |

`prop("Имя")` отдаёт значение свойства этой строки:

| Свойство | Тип в формуле |
|----------|---------------|
| Название, Текст, Ссылка, Email, Телефон | текст |
| Число, ID (номер без префикса) | число |
| Выбор, Статус | текст (название варианта) |
| Множественный выбор | список текстов |
| Дата, Создано, Изменено | дата |
| Флажок | флажок |
| Файлы и медиа | список текстов (имена файлов) |
| Связь | список страниц |
| Сводка | тип её итога |
| Формула | тип её итога |

Переименование свойства переписывает `prop("…")` во всех формулах базы. Удалённое свойство — ошибка «Нет свойства …» в редакторе, пустая ячейка в таблице.

## Синтаксис

- Литералы: `12`, `1.5`, `"текст"`, `true`, `false`, `[1, 2, 3]`.
- Операторы по старшинству: `( )`; `.` (метод); `not` `!`, унарный `-`; `^`; `*` `/` `%`; `+` `-`; `>` `>=` `<` `<=`; `==` `!=`; `and` `&&`; `or` `||`; `? :`.
- `+` складывает числа и склеивает текст (число с текстом — текст).
- Вызов функцией и методом равноправны: `length(prop("Имя"))` = `prop("Имя").length()`.
- Переменные: `let(имя, значение, выражение)`, `lets(имя1, значение1, имя2, значение2, …, выражение)`.
- В `map`, `filter`, `find`, `findIndex`, `some`, `every`, `sort` — `current` (элемент) и `index` (номер с 0).
- Комментарии `/* … */`; переводы строк и пробелы свободны.

## Функции

**Логика**: `if(усл, да, нет)`, `ifs(усл1, знач1, усл2, знач2, …, иначе)`, `and`, `or`, `not`, `empty(x)`, `equal(a, b)`, `unequal(a, b)`.

**Числа**: `add`, `subtract`, `multiply`, `divide`, `mod`, `pow`, `abs`, `round`, `ceil`, `floor`, `sqrt`, `cbrt`, `exp`, `ln`, `log10`, `log2`, `sign`, `min`, `max`, `sum`, `mean`, `median`, `pi()`, `e()`, `toNumber(x)`.

**Текст**: `length`, `concat` (тексты и списки), `join(список, разделитель)`, `split(текст, разделитель)`, `substring(текст, от, до?)`, `contains`, `startsWith`, `endsWith`, `lower`, `upper`, `trim`, `repeat`, `padStart`, `padEnd`, `replace`, `replaceAll`, `test`, `match` (регулярные выражения — как у Notion, синтаксис ICU), `format(x)` (любое значение в текст).

**Даты**: `now()`, `today()`, `minute`, `hour`, `day` (день недели, 0 — воскресенье), `date` (число месяца), `week` (ISO), `month` (1–12), `year`, `dateAdd(дата, n, ед)`, `dateSubtract`, `dateBetween(a, b, ед)`, `dateRange(начало, конец)`, `dateStart`, `dateEnd`, `timestamp`, `fromTimestamp`, `formatDate(дата, шаблон)`, `parseDate(текст ISO 8601)`.
Единицы: `"years"`, `"quarters"`, `"months"`, `"weeks"`, `"days"`, `"hours"`, `"minutes"`, `"seconds"`, `"milliseconds"`.
Шаблон `formatDate`: `YYYY YY Q MMMM MMM MM M DD D Do dddd ddd d HH H hh h mm m ss s A a` (как Moment.js у Notion); названия месяцев и дней — на языке macOS.

**Списки**: `at(список, n)`, `first`, `last`, `slice`, `concat`, `sort` (с выражением или без), `reverse`, `unique`, `includes`, `find`, `findIndex`, `filter`, `map`, `some`, `every`, `flat`, `length`, `sum`, `min`, `max`, `mean`, `median`, `join`.

**Страницы**: `current.prop("Имя")` у страницы из связи; `id()` — id этой строки, `id(страница)`.

## Не поддерживается (ошибка с названием функции)

`name`, `email` и всё о людях; `style`, `unstyle`, `link` (оформление итога); `prop` у свойств людей и кнопок; встроенные константы, которых нет в списке выше. Notion добавит новые функции — они ошибка, пока их не возьмут отдельным решением.

## Итог

- Тип итога выводится при сохранении. Итог-число показывается в формате, выбранном у свойства (форматы числа и «Показывать как», как у «Число»); итог-дата — в формате даты свойства.
- Деление на ноль, `toNumber("abc")`, пустое в арифметике — пустая ячейка без ошибки (как в Notion).
- Ошибка вычисления в отдельной строке (например, `at` за пределами списка) — пустая ячейка; в редакторе для строки-примера — текст ошибки.

## Редактор

Окно как у Notion 7.39: поле формулы с подсветкой (свойства — плашками, функции — цветом), слева снизу — список «Свойства», «Встроенные», «Функции» по разделам с поиском по набранному; справа — описание выбранного с синтаксисом и примером; под полем — итог для первой строки вида и ошибка.
Ошибки — по-русски, с подчёркиванием места: «Ожидалась „)“», «Нет свойства „Срок“», «Функция dateBetween ждёт дату, а получила текст», «Формула ссылается сама на себя: Итог → Сумма → Итог», «Функция style не поддерживается в MyNotion».
«Готово» неактивно, пока есть ошибка разбора или круг.

## Пересчёт

- Формула зависит от свойств своей строки и, через связи, от свойств связанных строк. Правка значения пересчитывает зависящие формулы и сводки этой строки и строк, связанных с ней, в той же записи.
- Формулы с `now()` или `today()` — «живые»: пересчитываются раз в минуту только у открытых видов и при открытии вида.
- Новая формула или правка формулы — пересчёт всех строк базы на очереди записи, пачками; до готовности ячейки показывают прежний итог (у новой — пусто).
