# MyNotion из командной строки

`mynotion` — команда для агентов: читает и правит заметки в работающем приложении MyNotion. Правки сразу видны в его окнах.

## Где команда

- `~/.local/bin/mynotion` — ссылка на `MyNotion.app/Contents/Helpers/mynotion`: команда всегда той же версии, что приложение.
- Приложение закрыто — команда сама запускает его в фоне, без захвата фокуса, и ждёт до 15 с (`--launch-timeout <с>`).
- Справка без приложения: `mynotion --help`, `mynotion <группа> --help`, `mynotion <группа> <команда> --help`. Весь каталог машинно: `mynotion commands --json` (поле `stage` — на каком этапе команда готова; не готовая отвечает `not_implemented`).

## Как вызывать

- Всегда ставить своё имя: `--agent Codex` или `MYNOTION_AGENT=Codex`. Оно попадёт в историю версий.
- Ответ — одна строка JSON в stdout: `{"ok":true,"data":…,"warnings":[…]}` или `{"ok":false,"error":{"code","message","hint","details"}}`. Читать `data` и `error.code`, не текст.
- `--human` — коротко для человека. Агенту не нужно.
- Списки: `{"items":[…],"nextCursor":…}`, по 200 (`--limit` до 1 000, дальше `--cursor <nextCursor>`).
- Изменяющая команда возвращает изменённый объект целиком: повторно читать не нужно.
- Приложение запущено с другой базой (своя папка и сокет) — `--socket <путь>` или `MYNOTION_SOCKET=<путь>` у каждой команды.

## Указатель страницы

- id или его начало от 8 знаков: `3f2a91c0`.
- Путь из названий через `/`: `"Проекты/Встреча 24.10"`. Регистр и ё/е не важны. `\/` — косая черта внутри названия.
- `current` — страница, открытая сейчас в переднем окне.
- Несколько подходящих — ошибка `ambiguous_page`, кандидаты в `error.details`. Взять нужный id и повторить.
- Страницы в корзине видны только с `--include-trashed`.
- Блок — только id, его берут из `mynotion page read <стр> --format json`.

## Коды выхода и ошибки

| Код | Что значит | Что делать |
|-----|-----------|-----------|
| 0 | успех | — |
| 2 | ошибка в вызове (`invalid_argument`, `missing_argument`, `invalid_value`…) | исправить по `hint`, допустимое — в `details.allowed` |
| 3 | не найдено (`page_not_found`…) | проверить указатель: `mynotion page tree --depth 2` |
| 4 | сейчас нельзя (`ambiguous_page`, `page_in_trash`, `window_busy`, `not_implemented`…) | уточнить или выбрать другое действие |
| 5 | приложение недоступно (`app_not_ready`, `timeout`…) | подождать и повторить; открыт лист — закрыть |
| 1 | сбой приложения | сообщить Юрию |

## Безопасность правок

- Перед первой правкой страницы за последние 10 минут приложение само сохраняет версию «до правки агента (имя)». Вернуть всё: история версий страницы.
- Правки агента не попадают в ⌘Z окон.
- Удаление — в корзину, возвращается. Окончательное удаление и очистка корзины — только с `--force`. Ставить его только по прямой просьбе Юрия.
- Команды не меняют настройки приложения, вход синхронизации, ключ Notion и внешний вид.
- Несколько связанных правок — одним `mynotion batch`: ошибка любого шага откатывает весь пакет.
